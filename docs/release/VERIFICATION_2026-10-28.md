# 목log 출시 후보 검증 기록

2026-10-28 (한국 시간). 심사 승인이나 임상 정확도 인증을 뜻하지 않는다.

## 구현

- 별도 출시 모듈 android/moklog, applicationId com.moklog.app, 이름 목log, 제공 로고.
- 기존 개발 모듈과 다른 설치 ID이므로 기존 기록을 덮어쓰지 않는다. 기록 자동 이전은 제공하지 않는다.
- 일반 운동 2종의 설명·주의사항·그림 순서 재생·타이머·실천 기록 연결. 외부 영상 미수령.
- 각도 평균과 참고 기준·경계에 걸친 값·품질 불량 시 해석 보류 안내.
- 첫 실행 개인정보·SDK 정보 및 참고 한계 확인, 설정의 개인정보 안내와 출처, 앱 내 오픈소스·SDK 고지 및 Apache/MIT 라이선스 동봉.
- API 36을 위한 화면 inset 처리와 OnBackPressedDispatcher 적용.
- 주간 실천 달력·실천 약속·시간/메모가 있는 일지·완료 피드백, 운동/사진 기록 탭. DB v3 메모 추가와 이전 데이터 보존.
- 샘플 활동·OCR·바코드·포즈 SDK와 저장소 접근 권한을 출시 모듈에서 제외.

## 실제 휴대폰 화면 조작

Galaxy S20 Ultra SM-G988N, Android 13, 1440×3200에서 확인했다. 처음에는 잠금 화면 뒤 실행만 확인했으나 사용자가 직접 잠금을 해제한 뒤 아래 경로를 조작했다. 기기 글꼴 설정은 변경하지 않았다.

| 경로 | 확인한 결과 |
| --- | --- |
| 첫 안내 → 개인정보 → 돌아가기 → 확인 → 목표 | 안내 확인 전 시작 비활성, 확인 후 목표 설정. 4주·3분의 검사용 목표 생성 |
| 오늘 → 운동 둘러보기 | 2종 선택, 자체 참고 그림·설명, 그림 순서 재생 확인 |
| 오늘 → 운동 시작 | 준비 확인 후 시작, 시간 감소, 일시정지, 계속하기, 중단 후 홈 복귀 |
| 기록 | 초기에는 실천 0일·측정 없음 화면 확인. 막바지에는 실천 1일·3분 표시 확인. 아래 기록 해석 참고 |
| 설정·개인정보 | 새 목표·출처·개인정보 안내·기록 관리 진입점과 오픈소스 라이선스 본문 열기/닫기 확인. 삭제는 실행하지 않음 |
| 홈 가로/세로 | 화면 폭 제한·스크롤·하단 탐색 표시 확인. 임시 회전 설정은 원래 값으로 복원 |
| 사진 점검 준비 → 카메라 → 취소 | 자동 촬영을 끈 상태로 권한 및 후면 CameraX device 0 연결, 수평 안내 문구, 취소 후 홈 복귀 확인 |
| 새 습관 화면 | 주간 달력·실제 실천 0일 진행률, 운동/사진 기록 탭·빈 상태 확인 |
| 실천 약속 | 임시 선택 → 앱 재실행 후 보존 → 해제 확인. 검사 선택은 지움 |
| 전체 타이머 | 3분 경과 후 오늘의 운동 기록·실제 수행 확인 화면 진입 확인. 운동 완료 저장은 수행하지 않음 |

카메라 연결을 위한 촬영 조건 체크박스 조작은 UI 검사이며 실제 C7 위치 확인의 증거가 아니다. 셔터를 누르지 않았고 사진·측정값을 저장하지 않았다. 캡처 보호 화면에서 이미지를 추출하지 않았다. 화면 관찰은 계측 검사 9개와 별도로 기록한다.

후반 일지 확인에서는 누적 1일·3분이 표시됐다. 에이전트는 실천 기록하기 버튼을 실행하지 않았으며, 이 기록이 실제 수행을 뜻하는지는 확인하지 않았다. 기록을 임의로 삭제하지 않았고 운동 효과 검증으로 제시하지 않는다. 전달 묶음의 빈 일지 화면은 앞서 0일 상태일 때 촬영한 UI다. 임시 충전 중 화면 유지 설정은 원래 값 0으로 복원했다.

## 배포물 구분

- Debug APK: 개발용, Play 제출 파일이 아님.
- Release QA APK: R8 축소·최적화를 적용하고 로컬 검증을 위해 debug 키로 서명했다. Play 업로드/릴리스 키가 아니며 공개 제출에 사용하지 않는다.
- Release AAB: 소유자 업로드 키를 받지 않아 미서명 후보 파일이다. 계정·소유자 입력 완료 후 submissionBundle로 다시 빌드한다.
- 스토어 이미지: 512×512 아이콘, 1024×500 그래픽.
- 개인정보처리방침 HTML·Data safety·등록정보는 초안이다. 운영자·실제 공개 연락처·URL·선언은 본인이 확정한다.

최종 미서명 AAB SHA-256: f1f6c16293d191f9b52d8a1133e4755391f3abc8804bff3073a532453d6f6540.
Release QA APK의 v1/v2/v3 서명 검증과 16KB zipalign을 통과했다. apksigner의 META-INF 항목에 대한 JAR 서명 경고는 남아 있으며 v2/v3 전체 APK 서명 검증 성공과 구분한다.
최종 QA APK 업데이트 후 검사용 목표가 유지되고 다시 첫 안내를 요구하지 않는 것도 확인했다.

## 아직 완료하지 않은 항목

- 실제 사람 촬영·귀/C7 위치·운동 시연·안내음 체감·기기별 정확도.
- 실제 운동 수행·날짜 변경·USB 분리 상태 실행. 기기에 표시된 1일·3분을 실제 운동 검증으로 세지 않는다.
- 메모 편집·키보드의 추가 사용성 점검과 실제 완료 후 피드백 사용성.
- Android 16 실제 기기의 edge-to-edge·제스처 복귀와 16KB 런타임.
- Play 계정 개설·본인 확인·업로드 인증서·공개 개인정보 URL·문의 이메일.
- 요구되는 비공개 테스트·프로덕션 접근 신청·Google 심사.
- 사용 권한이 확인된 외부 운동 영상 연결.

사진 보호를 해제하거나 실제 사진을 Git/출시 이미지로 수집하지 않았다. 테스트는 전용 DB 경로와 SharedPreferences를 사용하며, 기존 개발 앱의 저장 데이터를 삭제하지 않았다.

메모 DB 업그레이드 전 현재 목log의 DB·설정은 로컬 비공개 폴더에 백업했다. 공개 묶음에 포함하지 않는다. 버튼 픽셀 검사는 제품 DB를 사용하지 않는 Debug 전용 빈 Activity에서 수행하며, 이 Activity는 Release manifest에 없다. 실제 운동 완료나 치료 효과의 검증으로 세지 않는다.

AppCompat 1.7.1의 별도 배경 tint를 해제하는 공개 지원 메서드에는 해당 팩토리만 RestrictedApi lint 억제를 적용했다. 전체 lint 규칙을 끄지 않았다. 의존성 변경 시 실제 창의 버튼 색상 회귀 검사를 다시 실행한다.
