사진과 카메라

카메라 권한은 사진 점검에 사용합니다. 사진과 기준점 좌표는 기기 메모리에서 분석하며 사진 파일을 저장하거나 자체 서버에 전송하지 않습니다. 촬영 중단·화면 종료 시 사진 처리 흐름을 종료합니다.

기기 내 기록

목표 기간, 실천 약속, 운동 실천 날짜·루틴 시간·선택한 한 줄 메모, 사진별 각도·평균값·촬영 조건을 앱 내부에 저장합니다. 메모와 실천 약속은 사용자가 선택적으로 작성합니다. 메모 수정과 설정의 실천·측정 기록 삭제를 제공하고 앱 삭제 시 기기 내 정보가 제거됩니다. 계정·광고·자체 서버·기기 간 자동 동기화는 제공하지 않습니다.

Google ML Kit

귀 후보를 찾기 위해 bundled ML Kit Face Detection을 사용합니다. SDK는 기기·앱 정보, 설치별 식별자, 성능·오류·이벤트·API 설정·입출력 크기 등 진단 및 사용 분석 정보를 처리할 수 있습니다. Google 설명에 따르면 나열된 전송은 HTTPS로 암호화됩니다. 사진을 자체 서버에 보내지 않는 것과 SDK 진단 정보 처리는 서로 다릅니다.

건강 정보의 한계

목log는 의료기기가 아니며 질환을 진단·치료·완치·예방하지 않습니다. 각도는 자가 참고용이고 운동 그림은 실제 전문가 시연이 아닙니다. 의료적 조언은 전문가와 상담하세요.

보관·권리·변경 문의

사용자가 삭제하거나 앱을 제거할 때까지 기기 내 기록을 보관합니다. 자동 백업은 사용하지 않습니다. SDK의 원격 진단 정보 처리에 대해서는 Google 문서를 참고하세요. 권리 행사·문의는 위의 실제 운영자 이메일로 접수합니다. 처리 항목이나 목적이 변경되면 본 방침과 앱 내 고지를 갱신합니다.
