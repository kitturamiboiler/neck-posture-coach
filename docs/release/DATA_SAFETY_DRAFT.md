# Data safety 작성 보조 초안

2026-10-28 기준. 콘솔의 확정 답변이나 법률 의견이 아니다. 최종 AAB·SDK와 실제 콘솔 문항을 대조해 운영자가 제출한다.

| 정보 | 현재 앱의 처리 | 선언 검토 |
| --- | --- | --- |
| 사진·귀/C7 좌표 | 메모리 내 온디바이스 처리, 사진 파일·자체 서버 전송 없음 | 온디바이스 처리와 SDK 진단 전송을 혼동하지 않는다 |
| 운동 실천·각도·목표·촬영 조건·선택형 한 줄 메모·실천 약속 | 앱 내부 저장, 메모 수정·기록 삭제 가능 | 로컬 건강·운동 정보 및 사용자 작성 내용. 자체 서버로 수집하지 않는다는 범위를 명시 |
| 기기·OS·앱 정보 | ML Kit 진단/사용 분석에 사용될 수 있음 | 앱 정보·성능/진단 및 관련 데이터 유형 검토 |
| 설치별 식별자 | bundled ML Kit의 설치 단위 식별자 | Device or other IDs 검토. 사용자를 직접 식별하지 않는다는 이유로 무조건 미수집 처리하지 않음 |
| 지연·오류·API 설정·입출력 크기·이벤트 | ML Kit 진단·사용 분석 | Diagnostics / other app performance data / app interactions 등 실제 문항과 SDK 문서를 대조 |
| 이름·이메일·위치·연락처·음성 | 앱에서 요청·수집하지 않음 | SDK·향후 기능 변경 시 다시 검토 |
| 외부 출처 링크 | 사용자가 브라우저로 열 때 해당 사이트 적용 | 웹사이트의 별도 정책 안내 |

공식 SDK 설명: https://developers.google.com/ml-kit/android-data-disclosure

Google 문서에 따르면 SDK의 나열된 전송은 HTTPS 암호화되며 제3자에게 전달되지 않는다. 이 사실을 곧바로 앱의 모든 문항에 자동 적용하지 않는다. 수집/공유 정의, 서비스 제공자 예외, 필수/선택 여부와 삭제 정책은 최종 구성을 바탕으로 운영자가 확인한다.

계정이 없으므로 앱 계정 삭제 흐름은 없다. 앱 내 기록 삭제와 기기 앱 삭제를 안내한다. SDK 서버 데이터의 삭제까지 앱 버튼으로 보장한다고 쓰지 않는다.

건강 기능 선언은 별도로 작성한다. 운동 습관·일반 운동 안내와 카메라 자가 참고 기능을 숨기거나 단순 메모 앱으로 신고하지 않는다.
