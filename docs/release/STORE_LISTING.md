# 스토어 등록정보 초안

앱 이름: 목log

짧은 설명:
매일의 운동 실천을 기록하고, 같은 조건의 옆모습 사진으로 자세를 살펴보세요.

## 자세한 설명

목log는 가벼운 운동을 꾸준히 실천하고 기록하는 앱입니다.

- 2주 또는 4주, 하루 3분 또는 5분의 실천 목표
- 일반 운동의 단계별 설명과 그림 순서 안내
- 시작·일시정지 가능한 타이머와 실제 수행 확인 후 실천 기록
- 실천할 순간을 정하는 약속, 주간 실천 달력과 누적 기록
- 날짜별 운동 일지와 선택형 한 줄 메모·수정
- 옆모습 사진 3장, 귀·C7 기준점 직접 확인과 평균 각도
- 같은 촬영 조건의 기록을 비교하는 자가 점검
- 기기 내 기록 저장과 삭제

사진 점검에는 카메라 권한과 기기 수평 확인, 사전에 확인한 C7 표식 및 사용자의 기준점 확인이 필요합니다. 측면 검출과 촬영 품질은 기기·조명·거리·가림에 따라 달라집니다. 확인되지 않은 모든 휴대폰에서 동일한 성능을 보장하지 않습니다.

사진은 기기에서 처리하고 파일로 저장하거나 자체 서버로 업로드하지 않습니다. 별도 로그인·광고·자체 서버가 없습니다. Google ML Kit의 기기·앱·성능 진단 정보 처리는 개인정보처리방침을 확인하세요.

목log는 의료기기가 아니며 어떤 질환도 진단·치료·완치·예방하지 않습니다. 사진 각도는 참고값이고 거북목 여부나 중증도를 확정하지 않습니다. 운동 기간은 습관 목표이며 회복 기간을 예측한 것이 아닙니다. 의료적 조언·진단·치료는 의료 전문가와 상담하세요. 통증·어지럼·저림이 생기면 운동을 중단하세요.

현재 그림은 자체 제작한 AI 보조 참고 이미지이며 전문가의 실제 시연 영상이 아닙니다. 외부 기관과의 제휴·인증을 의미하지 않습니다.

## 올리기 전

- 실제 배포 버전과 설명이 일치하는지 확인한다.
- '정확한 거북목 진단', '완치', '임상 인증', '모든 기기 지원' 같은 미검증 주장은 추가하지 않는다.
- 운영자·문의 이메일·공개 개인정보 URL, 출시 지역·가격·연령은 소유자가 확정한다.
- 스크린샷은 실제 앱 화면을 사용한다. 측정 시연 수치를 실제 임상 실험 결과로 설명하지 않는다.
