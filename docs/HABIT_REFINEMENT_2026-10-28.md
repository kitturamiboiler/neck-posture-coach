# 목log 운동 습관·일지 보완

작성일: 2026-10-28. 사용자 요청에 따라 출시 준비와 함께 실제 Android 앱을 수정했다.

## 방향

목log는 짧은 일반 운동을 일상에 연결하고, 실천을 남긴 뒤 같은 조건의 사진으로 자세를 살펴보는 앱이다. 실천 횟수와 각도는 서로 다른 정보이며 운동 기록이 늘었다고 치료 효과를 확정하지 않는다.

라이즈의 공식 소개에서 빠른 운동 기록, 루틴 안내, 지난 기록 확인이라는 사용 패턴을 참고했다. 해당 앱의 화면·아이콘·영상·문구를 복제하지 않았다.

- 라이즈 공식 등록정보: https://play.google.com/store/apps/details?hl=ko&id=com.cheezebucket.rise
- 목표·행동 계획·자기 기록·피드백의 설계 참고: https://www.nice.org.uk/guidance/ph49/chapter/recommendations

위 자료는 기능 선택의 참고이며 목log 자체의 습관 형성 효과를 검증했다는 뜻은 아니다.

## 화면에 반영한 내용

| 화면 | 역할과 구현 |
| --- | --- |
| 오늘 | 오늘의 루틴을 주요 행동으로 표시. 목표 진행 막대는 실제 실천일 수로 계산하고, 이번 주 달력과 다음 사진 점검을 연결 |
| 실천 약속 | 식사·일과·취침처럼 기존 일상 뒤에 연결할 순간을 선택하거나 60자 이내로 직접 작성. 설정에서 수정·해제 가능 |
| 운동 | 일반 운동 2종, 자체 참고 그림과 순서 재생, 주의사항, 타이머 시작·정지·계속하기 |
| 완료 확인 | 타이머 종료 후 실제 수행 여부를 확인하고 280자 이내 한 줄 기록을 선택적으로 작성 |
| 완료 피드백 | 저장된 기록이 있을 때만 완료 화면과 주간 달력을 표시. 놓친 날 때문에 실패했다고 표현하지 않음 |
| 운동 일지 | 누적 실천일·휴식이 포함된 기록 시간·주간 달력·날짜별 메모와 수정. 처음에는 최근 30건, 이후 더 보기 |
| 사진 점검 기록 | 운동 일지와 탭을 분리. 사진별 값·평균·같은 조건 비교·삭제 흐름 유지 |
| 설정·개인정보 | 실천 약속, 운동 안내, 기록 관리, 개인정보·출처. 개발 식별자나 출시 전 검증용 문구를 제품 안내에서 제거 |

실천 약속은 앱 안에서 보여 주는 행동 계획이다. 푸시 알림·예약 알림을 구현한 것으로 표시하지 않는다.

## 디자인 기준

- 기존 Figma 스타일의 초록색·밝은 배경·카드·고정 하단 탐색을 유지했다.
- 시작·저장은 채운 주요 버튼, 둘러보기·취소·되돌아가기는 테두리 버튼으로 구분한다.
- 아이콘과 문구를 한 묶음으로 중앙 정렬하고, 긴 문구는 줄바꿈한다.
- 비활성 버튼은 배경과 글자 상태를 함께 바꾼다. 새 배경의 상태 초기화 문제로 활성 버튼이 회색으로 보이는 현상을 재현해 공통 버튼에서 수정했다.
- 주간 달력은 실제 완료 데이터만 표시한다. 큰 글꼴에서는 두 줄로 나누고, 날짜·완료 여부·오늘을 접근성 설명으로 제공한다.
- 임의의 완료 수·메모·각도를 넣어 화면을 채우지 않는다.
- 개발용 문구를 정리하더라도 의료적 한계, 운동 중단 조건, 개인정보·SDK 고지는 유지한다.

## 저장과 리팩터링

- PostureStore DB v3: 실천 행에 note를 추가. v1은 기존 평균 전환 뒤 note를 추가하고, v2는 note만 추가한다.
- 사진별 값·기존 중앙값·평균·실천 시간·목표는 삭제하거나 덮어쓰지 않는다.
- 같은 목표의 같은 날짜에 다시 완료해도 기존 실천을 중복 저장하거나 메모를 자동으로 덮어쓰지 않는다.
- 메모 수정은 해당 목표·날짜의 행만 바꾸며 실천 시간과 측정값은 변경하지 않는다.
- HabitProgress는 월요일 시작 주간 날짜와 완료일 집계를 계산한다. 연도 경계·윤일·중복·미래일·잘못된 날짜를 검사한다.
- 공통 입력·달력·버튼은 CoachUi, 운동/사진 기록 화면은 각각의 구성 메서드로 분리했다.
- 업그레이드 전 현재 설치본의 기기 내부 DB·설정 스냅샷을 로컬 비공개 폴더에 보관했다. 공개 배포 묶음과 Git에 포함하지 않는다.
