# 촬영·평균값·UI 작업 기록

작성일: 2026-10-23 (한국 시간)
작업 브랜치: feat/capture-guidance

10월 23일 사용자 요청으로 dev에 병합·푸시한다. 실제 사람의 측정은 사용자가 직접 수행하며, 이 작업의 검사 결과와 구분한다.

## 범위

사용자의 10월 23일 요청에 따라 자동 촬영, 촬영 알림, 평균값 전환, UI 보완을 진행했다. 운동 콘텐츠는 보류했다. 종전의 10월 27일 이후 계획보다 먼저 착수한 변경이며 과거 작업 날짜를 변경하지 않는다.

가이드의 실제 픽셀 표시 검사 1개를 추가해 테스트 APK 빌드까지 확인했다. 이 추가 검사는 아직 실행하지 않았으므로 위의 통과한 14개에 포함하지 않는다. 사용자가 실촬영을 진행하므로 추가 계측으로 앱 조작을 중단시키지 않는다.

## 기존 테스트의 데이터 격리 문제

- 기존 PostureFlowTest는 Context의 openOrCreateDatabase만 재정의했다. 현재 Android의 SQLiteOpenHelper는 getDatabasePath를 사용하므로 실제 기록 DB에 접근할 수 있었다.
- 이번 첫 검사에서 실제 기록 DB에 삭제 동작이 실행된 것을 확인했다. 당시 사전 백업이 없어 삭제 전 행 수나 기존 행의 복구를 보장할 수 없다.
- 발견 즉시 사용자에게 알리고 getDatabasePath도 테스트 전용 경로로 격리했다. 삭제 전에 실제 열린 DB 경로를 검사하는 assertion을 추가했다.
- 수정 후 계측 14개 통과 및 실제 DB 파일의 전후 해시 일치를 확인했다.
- 문제 발견 후 보관한 로컬 DB는 이미 검사 후 상태다. 삭제 전 백업이나 복구본이라고 표현하지 않는다. 검색한 로컬 artifacts/output 위치에서는 기존 DB 백업을 찾지 못했다.
- 과거 기록 보존 보고 중 이 자동 테스트의 격리에 근거한 부분은 정정한다. DB 업그레이드 보존 자체는 수정된 격리 테스트에서 별도로 검증했다.
- 실제 기록·로컬 백업 DB·사용자 사진은 Git에 넣지 않는다.

## 남은 실사용 확인

- 평균 아래의 각도 해석·참고 기준 문구는 아직 미반영이다. 거북목 확정 판정이나 정상·중증 등급 기능을 구현한 것으로 표시하지 않는다.

- 실제 옆모습에서 전/후면 자동 시작과 3장 완료, 구도 이탈·기기 기울기·중단 복귀.
- 안내음 구분과 진동 체감, 음소거·방해금지 상태.
- 갤탭 가로/세로, 큰 글꼴, 작은 화면 및 S20 Ultra 실기기.
- 카메라별 미리보기와 가이드의 실물 위치 대조.
- 평균값 방식의 반복 실촬영 및 저장·비교. 의료적 정확도 검증은 별도다.

DB v2 적용 후 과거 v1 앱으로의 다운그레이드는 지원하지 않는다. 기존 APK를 다시 설치하기 위해 앱을 삭제하거나 데이터를 초기화하지 않는다.
