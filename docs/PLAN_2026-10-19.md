# 10월 26일 발표 및 이후 개발 계획

발표일: 2026-10-26. 작성일: 2026-10-18.

2026-10-23 변경: 사용자가 촬영·알림·평균값·UI 네 가지 개발을 지금 진행하도록 요청해 선행 착수했다. 아래 표는 10월 18일의 계획 이력이며, 최신 구현·검증 상태는 [10월 23일 작업 기록](CAPTURE_WORKLOG_2026-10-23.md)을 따른다. 운동 콘텐츠는 보류한다.

최신 사용자 결정: 10월 26일까지는 설계·프로토타입과 기존 기능을 발표하고, 정식 UI 적용·완성과 사진 로직 개선은 10월 27일 이후에 진행한다. 10월 18일 UI 1차 적용·갤탭 검증 사실은 보존하되 정식 적용 완료와 구분한다. 파일명은 기존 링크 유지를 위해 유지한다.

## 2. 자동 촬영 구현 조건

- 구도 가이드와 실제 카메라 영상의 확대·여백·회전·전면 반전을 일치시킨다.
- 틀 안에 들어온 얼굴 구도와 기기 수평이 연속 유지되는 조건을 정한다. 약 2초를 초기 후보로 검토하되 실기기에서 조정한다.
- 얼굴이 보인다는 것과 귀·C7 기준점이 정확하다는 것은 다르다. C7 자동 검출로 표현하지 않고 기존 사람 확인 절차를 유지한다.
- 측면 얼굴 검출이 불안정하면 자동 촬영을 강행하지 않는다. 원인 안내와 수동 촬영 경로를 남긴다.
- 구도 이탈·기울기·앱 중단 시 대기를 초기화하고 중복 촬영 시작을 차단한다.
- 촬영 중 미리보기 가림과 시간 간격을 둔 3장 촬영, 사진 미저장 원칙을 유지한다.
- 의도적으로 턱을 당긴 자세를 완전히 검출할 수 있다고 주장하지 않는다.

## 3. 소리·진동 안내

- 카메라 진입 전 소리 안내를 켜 달라는 안내를 제공한다. 음량을 앱이 임의로 올리지 않는다.
- 수평이 맞는 상태로 바뀌었을 때만 한 번 알린다. 센서 갱신마다 반복 재생하지 않고 재알림 간격을 둔다.
- 수평 확인음과 촬영음을 구분하고 화면 문구도 함께 제공한다.
- 안내음은 실제 사진 수신 성공을 기준으로 내보낸다. 실패했는데 촬영 완료로 안내하지 않는다.
- 음소거·방해금지 상태를 고려하고 소리 없이도 사용할 수 있게 한다.
- 앱 이탈 시 예정된 안내음과 진동을 정리한다.

## 4. 평균값 전환

- 표시 문구만 바꾸지 않고 계산·저장·최근 결과·기록 간 차이를 함께 변경한다.
- 기존 사진별 측정값과 중앙값은 삭제하지 않는다. 기존 기록의 평균 재계산 및 DB 업그레이드 방식을 정하고 보존 검사를 추가한다.
- 사진별 값과 촬영 조건을 계속 표시하고, 측정 편차가 큰 경우의 저장 제한을 유지한다.
- 평균이 중앙값보다 의학적으로 더 정확하다는 의미로 설명하지 않는다. 이번 변경은 제품의 대표값 표시 방식에 대한 결정이다.
- 과거 실험 기록의 중앙값 수치는 당시 결과로 보존한다. 새 방식과 혼동하지 않도록 계산 방식을 명시한다.
