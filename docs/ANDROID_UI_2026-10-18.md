# Android UI 반영 및 10월 26일 발표 준비

작성일: 2026-10-18 (한국 시간)

## 1. 작업 범위

Figma 프로토타입을 참고해 실제 Java Android 앱을 수정한다. Figma 화면이나 시연 영상을 앱에 통째로 넣는 방식이 아니다. 측정 계산, 카메라, 로컬 기록은 기존 구현을 재사용한다.

- 작업 브랜치: `feat/figma-android-ui` (`dev`에서 분기)
- 디자인: https://www.figma.com/design/UVoh6FIEUxdfsjejy34Hbz
- 기준 화면: 목표 설정, 오늘, 운동, 사진 점검 준비, 기준점 확인, 결과, 기록, 설정
- 사용자 사진 저장·전송 없음. 사진 화면의 캡처 보호 유지.

## 2. 코드 반영

| 화면 / 공통 요소 | 반영 내용 | 확인 범위 |
| --- | --- | --- |
| 공통 UI | 초록·연한 초록·회백색, 여백, 제목, 표면·테두리, 버튼 상태 | 공통 `CoachUi` 사용 |
| 버튼 | 아이콘과 글자를 하나의 묶음으로 중앙 정렬, 최소 48dp, 줄바꿈 | 계측 테스트 추가 |
| 반응형 | 콘텐츠 최대 600dp 중앙 배치, 세로 스크롤, 큰 글꼴 선택지 세로 전환 | 폰 실기기 검증 별도 필요 |
| 목표 설정 | 2/4주와 3/5분 선택지, 시작 버튼 강조 | 기존 목표 저장 재사용 |
| 오늘 | 목표·실천 카드, 사진 점검·기록 버튼, 오늘/기록/설정 하단 탐색 | 실제 저장 데이터 표시 |
| 운동 | 운동 자료 공간, 원형 타이머 표시, 시작·정지 버튼 스타일 | 운동 자료는 미수령 |
| 사진 준비·촬영 | 선택지·버튼·뒤로가기 스타일 통일 | 수평 검사·3장 촬영 유지 |
| 기준점 확인 | 조정 버튼 정렬, 확인 버튼 상태, 뒤로가기 | 귀·C7 수동 확인 유지 |
| 결과 | 대표 각도, 사진별 값, 촬영 조건, 저장 버튼 | 중앙값·품질 검사 유지 |
| 기록·설정 | 측정별 카드와 하단 탐색 | 삭제 확인·기존 저장 구조 유지 |

시안의 폰트와 아이콘을 새 의존성으로 추가하지 않았다. 글꼴은 Android 시스템 글꼴, 아이콘은 기존 Android 리소스를 사용한다. 시안과 완전히 동일한 폰트·아이콘이라는 의미는 아니다.

## 3. 운동 자료 반영 조건

- 조원에게 받은 자료의 출처·앱 배포 사용 허용 여부를 확인한다.
- 확정된 운동명·이미지·안내를 실제 운동 단계에 연결한다.
- 현재 자료 공간은 준비 중 상태이며, 임의의 의학적 운동 처방이나 가짜 자료를 넣지 않는다.
- 타이머 종료만으로 수행을 단정하지 않고 사용자의 실제 수행 확인 후 기록하는 규칙을 유지한다.

아래는 예정이며 완료 이력이 아니다. 운동 자료 수령과 실기기 연결 여부에 따라 조정한다.

| 10/19~25 | UI 설계·Figma 프로토타입 및 발표 자료 정리 | 기존 구현·1차 적용 실험·미완료 범위를 구분 |

Google Play 정식 출시는 이번 발표 완료 조건과 분리한다. 측정 정확도 입증, 출시 정책·개인정보·배포 설정 검토를 UI 작업 완료로 대체하지 않는다.

최신 사용자 결정에 따라 정식 UI 적용·완성과 구도 틀·자동 촬영·소리/진동 알림·평균값 전환은 26일 이후 범위다. 상세 일정과 완료 조건은 [발표 및 이후 개발 계획](PLAN_2026-10-19.md)을 기준으로 한다. 현재 앱은 수동 촬영 시작·중앙값 방식을 유지한다.

## 5. 검증 기록

- CVA 독립 계산 검사: 18개 통과.
- Debug 앱·테스트 APK 빌드 통과.
- `lintDebug` 작업 성공. 기존 Kotlin 메타데이터 버전 경고가 있어 경고 없는 검사 결과로 표현하지 않는다.
- 갤탭 SM-T735N: 기존 데이터를 초기화하지 않고 `adb install -r`로 업데이트 설치 성공.
- 갤탭 계측 검사 12개 통과: `CoachUiTest` 2개, `PostureFlowTest` 2개, `NeckPostureAngleTest` 8개.
- 버튼 검사는 288/328/568dp 너비에서 아이콘·문구 중앙 정렬과 문구 변경 후 재정렬을 확인했다. fontScale 2 설정의 긴 문구 줄바꿈·높이와 선택지 세로 배치도 검사했다.
- 위 너비 검사는 갤탭에서 생성한 View의 계측 검사이며, S20 Ultra 실기기 확인을 대체하지 않는다.
- 갤탭 홈 가로·세로 화면을 캡처해 콘텐츠 중앙 배치와 하단 탐색을 확인했다. 회전 설정은 검사 후 기존 값으로 복원했다.
- 실제 버튼 조작으로 오늘 → 기록 → 설정 → 오늘 → 운동 화면, 오늘 → 사진 점검 준비 화면 이동을 확인했다. 사진 점검 종료 확인 후 오늘 화면으로 복귀했다. 운동 완료나 새 측정 기록은 만들지 않았다.
- 기기에 적용된 사용자 글꼴·화면 색상 설정에 따라 시안과 외형 차이가 있을 수 있다. 사용자 설정을 초기화하지 않았다.
- 이번 UI 작업에서 새 실촬영 측정값이나 정확도 수치를 만들지 않았다.

### 남은 검증

- S20 Ultra: 작은 화면 실제 조작, 시스템 큰 글꼴, 카메라, USB 분리 후 재실행.
- 새 UI의 사진 3장 실촬영 → 귀·C7 확인 → 결과 저장 전체 흐름. 이전 실촬영 결과와 이번 UI 검증을 혼합하지 않는다.
- 운동 자료 연결 후 실제 운동·완료 기록 및 날짜 변경 검증.
- Google Play 출시를 위한 별도 점검.
