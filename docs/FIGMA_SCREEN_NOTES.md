# 화면별 구성 및 구현 의도

작성일: 2026-10-11. 대상: 목 자세 코치 Android Figma 초안.

이 문서는 Figma의 `03 Guide & Review` 페이지를 `03 Screen Notes`로 바꿀 때 사용할 화면 제작 기록입니다. 아래 문서 원본은 작성했으며 Figma 페이지 교체는 MCP 호출 한도와 브라우저 로그인 부재로 아직 반영하지 못했습니다.

## 목표 설정

2주/4주와 하루 3분/5분을 선택지로 배치했습니다. 목표 선택을 위쪽에, 목표 설명과 시작 버튼을 아래쪽에 두었습니다. 선택한 조합에 해당하는 오늘 화면으로 이동하도록 연결했습니다.

## 오늘 화면

오늘의 인사, 목표와 경과일, 실천 상태, 운동 시작, 다음 사진 점검, 기록 진입 순서로 구성했습니다. 운동 시작은 주색 버튼, 사진 점검과 기록 보기는 보조 버튼으로 구분했습니다. 하단에는 오늘·기록·설정 이동을 배치했습니다.

## 운동 루틴

운동명·설명과 이미지 영역, 타이머, 상태 확인, 시작 버튼을 배치했습니다. 운동 가능한 상태를 확인하기 전에는 시작 버튼을 비활성화합니다. 확인 후 시작·일시정지·재개·완료 확인으로 연결했습니다. 종료 후 실제 수행 여부를 확인하도록 구성했습니다.

## 사진 준비와 촬영

촬영 자세 안내, 좌우와 전후면 선택, C7 위치 확인, 카메라 열기를 배치했습니다. 기본 흐름에서는 조건 확인 후 카메라 권한 화면을 거쳐 촬영 상태로 이동합니다. 실제 카메라 영상 대신 상태 전환을 표현했습니다.

## 사진별 기준점 확인

사진 3장을 각각 확인 전후 상태로 구성했습니다. 귀·C7 확인 문구와 다음 사진 버튼, 재촬영을 배치했습니다. 확인 체크 전에는 다음 단계로 진행하지 못하게 연결했습니다. 사진과 귀·C7 오버레이, 위치 이동 조작은 실제 콘텐츠와 함께 보완해야 합니다.

## 사진 점검 결과

대표 각도, 세 사진의 값, 촬영 조건, 참고 문구, 저장·기록 보기·기준점 재확인 순서로 구성했습니다. 대표값을 강조하고 사진별 값은 동일 크기의 컴포넌트로 배치했습니다. 정상·위험 등급은 표시하지 않습니다. 저장하지 않은 결과에서 기록으로 이동할 때는 저장 여부를 확인합니다.

## 기록과 설정

기록은 운동 실천과 사진 점검을 구분하고 날짜·각도·촬영 조건을 표시했습니다. 개별 측정 삭제와 빈 기록 화면을 연결했습니다. 설정에는 개인정보 안내, 전체 삭제, 측정 안내와 운동 출처를 배치했습니다.

## 예외 상태

권한 거부·재시도, 저장 실패·재시도, 측정값 차이가 큰 경우의 보류·재확인·재촬영을 구성했습니다. 상태별로 다음에 할 행동을 버튼으로 제시했습니다.

## 공통 버튼 정렬 보완 요청

사용자가 제시한 오늘 화면에서 버튼의 아이콘·글자 가운데 정렬을 다시 검수해야 합니다. 개별 화면을 임의로 옮기기보다 메인 Button 컴포넌트를 수정하고 모든 인스턴스에 반영합니다.

- 가로 Auto Layout에서 아이콘과 글자를 하나의 묶음으로 취급하고 주축·교차축을 모두 가운데 정렬합니다.
- 버튼 좌우 패딩을 동일하게 설정합니다. 아이콘은 24px, 간격은 8px를 유지합니다.
- 라벨은 내용에 맞는 너비와 높이로 설정합니다. 고정 라벨 폭이나 숨긴 아이콘의 빈 공간이 시각적 중심을 밀지 않는지 확인합니다.
- 인스턴스 너비 296px와 328px, 아이콘 표시·숨김, 짧고 긴 문구, Default·Disabled·Loading을 함께 확인합니다.
- 카드 안의 운동 시작과 본문 사진 점검·기록 보기 버튼의 실제 중심을 비교합니다.

위 정렬 수정은 아직 Figma에 적용하지 못했습니다. 원래 생성 코드에는 가운데 정렬을 지정했지만 실제 렌더링이 사용자 기대와 다른 사례가 있어 재검수 대상으로 남깁니다.

## 현재 범위

원안 Pretendard 대신 Noto Sans KR을 임시 사용했습니다. 운동 콘텐츠와 사진 조작은 보완이 필요합니다. Starter 플랜 제약으로 전역 목표·촬영 조건·기록의 실제 유지와 동기화는 구현하지 않았으며, 기본 4주/3분·왼쪽/전면 예시로 흐름을 검토합니다. 이 화면은 실제 Android 앱에 반영된 상태가 아닙니다.
