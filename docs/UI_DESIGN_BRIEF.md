# 목 자세 코치 UI 디자인 작업 지침서

작성일: 2026-10-04

전달 대상: 팀 UI 디자인 담당자

앱 이름: 목 자세 코치 (현재 작업명)

## 1. 이번 작업의 목표

앱 전체에서 함께 사용할 **색상, 한글 글꼴, 아이콘 스타일**을 제안하고, 이를 적용한 대표 화면 시안을 만들어 주세요. AI 도구를 활용해도 괜찮습니다.

이번 시안은 팀이 시각 스타일을 선택하기 위한 자료입니다. 전달받은 자료를 바탕으로 개발 담당자가 UX 레이아웃을 정리하고 Figma를 제작합니다.

| 디자인 담당자에게 요청하는 일 | 개발 담당자가 이어서 할 일 |
| --- | --- |
| 공통 색상·글꼴·아이콘 조사 및 추천 | 화면 정보의 우선순위와 최종 배치 결정 |
| 참고할 앱·디자인 사례 정리 | 화면 사이의 이동 흐름 결정 |
| 선택한 스타일을 적용한 대표 화면 시안 | Figma 구성 및 실제 앱 구현 |
| 사용한 자료의 출처·사용 조건 정리 | 다양한 휴대폰 크기·글자 크기에 맞춘 조정 |

## 2. 어떤 앱인가요?

매일 짧은 운동을 실천하고 기록하면서, 일정 간격으로 옆모습 사진을 찍어 자세 관련 수치의 변화를 확인하는 Android 앱입니다.

사용 흐름은 **목표 설정 → 첫 사진 점검 → 운동·실천 기록 → 이후 사진 점검 → 기록 비교**입니다.

- 사용자가 목표 기간 2주 또는 4주, 하루 운동 시간 3분 또는 5분을 선택합니다.
- 사진 점검에서는 사진 3장을 찍고 귀와 C7(목 아래쪽의 사전에 확인한 기준점)을 확인합니다.
- 앱은 두 점을 연결한 선과 수평선 사이의 각도인 CVA를 계산합니다.
- AI가 귀 후보를 제안하며, 실제 기준점은 사용자가 확인합니다.
- 운동 기록과 측정값은 기기 안에 저장됩니다.

디자인은 **일상에서 부담 없이 운동을 이어가는 앱**이라는 느낌을 중심으로 제안해 주세요. 결과 화면에는 각도와 기록을 읽기 쉽게 보여주세요.

## 3. 필요한 자료: 1차 제출 총 4장

앱 화면 3장과 스타일 보드 1장을 요청합니다. 먼저 하나의 일관된 스타일로 완성해 주세요. 다른 방향의 아이디어가 있으면 참고 자료로 추가해도 됩니다.

| 번호 | 제출물 | 크기: Width × Height | 넣을 내용 |
| --- | --- | --- | --- |
| 01 | 공통 스타일 보드 | 1440 × 1000 | 색상, 글꼴, 아이콘 예시, 버튼·선택지 예시, 참고 디자인 |
| 02 | 오늘 화면 시안 | 360 × 800 | 목표 기간·시간, 오늘의 실천 상태, 운동 시작, 사진 점검, 기록 접근 |
| 03 | 운동 루틴 화면 시안 | 360 × 800 | 운동 이름·안내, 운동 그림 영역, 타이머, 시작·일시정지, 수행 완료 확인 |
| 04 | 사진 점검 결과 화면 시안 | 360 × 800 | 사진 3장의 각도, 대표값, 촬영 조건, 참고용 안내, 저장·기록 접근 |

**크기는 디자인 프레임 기준 px입니다.** 실제 휴대폰의 스크린샷 해상도와 다를 수 있습니다. Figma에서 작업한다면 위 크기로 Frame을 만들면 됩니다. 다른 도구에서도 같은 비율과 크기로 작업해 주세요.

### 화면 크기 작업 기준

- 휴대폰 시안은 세로 화면 `360 × 800` 한 종류로 작업합니다.
- 좌우 여백은 각각 16을 참고하면 내용 영역의 너비는 328입니다.
- 화면 안에 들어가지 않는 내용은 스크롤로 이어질 수 있도록 표현하면 됩니다.
- 시스템 상태 표시줄과 하단 내비게이션 영역은 앱 내용과 구분해 주세요.
- 버튼 높이는 48 이상, 아이콘 그림은 24 정도를 시안 참고값으로 사용할 수 있습니다.
- 태블릿, 가로 화면, 다른 휴대폰 크기의 별도 시안은 1차 제출에 포함하지 않습니다. 실제 크기와 시스템 여백 조정은 개발 담당자가 진행합니다.

위 여백과 버튼 크기는 시안을 만들기 위한 참고값입니다. 최종 레이아웃은 전달 후 정리합니다.

## 4. 스타일 보드에 정리할 내용

### 색상

주요 색상 하나를 중심으로 화면에 사용하는 색상을 용도별로 정리해 주세요. 각 색상은 **HEX 코드와 사용 목적**을 함께 적어 주세요.

| 색상 용도 | 정리할 내용 |
| --- | --- |
| 주요 색상 | 운동 시작 등 핵심 행동에 사용할 색상 |
| 배경·표면 | 전체 배경과 내용 영역의 색상 |
| 기본·보조 글자 | 제목·본문과 덜 중요한 설명의 색상 |
| 구분선·비활성 | 선, 비활성 버튼 등에 사용할 색상 |
| 완료·주의·오류 | 실천 완료, 촬영 재확인, 저장 실패 같은 상태에 사용할 색상 |

완료·주의·오류는 색뿐 아니라 아이콘 또는 짧은 문구로도 구분해 주세요. 결과 화면의 색은 질환의 정상·중증 등급을 나타내는 용도로 사용하지 않습니다.

### 글꼴

한글을 잘 읽을 수 있는 글꼴 한 종류를 우선 추천해 주세요. 숫자, 타이머, 각도 기호 `°`도 함께 확인해 주세요.

| 항목 | 제출할 정보 |
| --- | --- |
| 글꼴 | 정확한 이름, 제공처 링크 |
| 굵기 | 본문·제목·버튼에 사용할 굵기 |
| 크기 예시 | 화면 제목 20~24, 본문·버튼 16, 보조 설명 14 정도 |
| 사용 조건 | 앱 배포 시 사용 가능 여부와 출처 표시 조건 |

스타일 보드에서 같은 문장을 제목·본문·보조 설명으로 보여주세요. 예: “오늘도 3분, 꾸준히 실천해요.”

### 아이콘

같은 아이콘 세트에서 다음 항목의 예시를 골라 주세요.

**오늘 / 운동 / 카메라 / 기록 / 설정 / 뒤로 / 시작 / 일시정지 / 완료 / 삭제**

- 세트 이름, 제공처 링크, 앱에서 사용할 수 있는 조건을 적어 주세요.
- 선 두께와 채움 방식이 일관된 아이콘을 골라 주세요.
- 가능하면 SVG 원본 또는 원본을 받을 수 있는 링크를 전달해 주세요.

### 참고 디자인

참고 사례 2~3개를 링크와 함께 정리해 주세요. 각 사례에서 참고하고 싶은 점을 한 문장으로 적어 주세요. 예: “타이머 숫자의 가독성”, “완료 상태의 색상”, “기록을 보여주는 방식”.

## 5. 대표 화면에 사용할 예시 내용

배치는 자유롭게 제안해 주세요. 아래 내용이 눈에 잘 들어오는지 판단할 수 있도록 시안을 만들어 주세요.

### 02 오늘 화면

- 목표: “4주 동안 하루 3분”
- 진행: “3일차”
- 실천 상태: “오늘 운동을 아직 기록하지 않았어요”
- 주요 행동: “운동 시작”, “사진 점검”
- 기록을 확인할 수 있는 요소

### 03 운동 루틴 화면

- 제목: “오늘의 운동”
- 운동 설명이 들어갈 공간
- 운동 그림 또는 이미지가 들어갈 공간
- 타이머 예시: “03:00”
- 시작·일시정지와 수행 완료 확인 요소

운동 그림은 배치 공간만 표시해도 됩니다. 새 운동 동작이나 효과 설명을 작성할 필요는 없습니다.

### 04 사진 점검 결과 화면

- 제목: “사진 점검 결과”
- 각도 예시: 첫 사진 `52.5°`, 두 번째 `55.4°`, 세 번째 `55.7°`
- 대표값: `55.4°` (세 값의 중앙값)
- 촬영 조건: “서 있는 자세 · 왼쪽 · 전면 카메라”
- 안내: “자가 참고용 수치입니다.”
- 저장과 기록 확인 요소

위 수치는 이전 앱 동작 확인에서 사용한 예시입니다. 시안에는 “정상”, “거북목 확진”, “치료 완료” 같은 판단 문구를 넣지 마세요.

## 6. 최종 앱의 화면 목록: 참고용 9개

아래는 이후 UX와 Figma를 구성할 때 필요한 전체 화면 목록입니다. **이번 1차 요청은 앞서 정한 대표 화면 3개만** 해당합니다.

| 화면 | 역할 | 이번 제출 |
| --- | --- | --- |
| 목표 설정 | 기간 2주/4주, 시간 3분/5분 선택 | 참고 |
| 오늘 | 진행 상태와 주요 행동 | 시안 요청 |
| 운동 루틴 | 운동 안내·타이머·완료 확인 | 시안 요청 |
| 사진 점검 준비 | 촬영 방향·카메라·기준점 준비 안내 | 참고 |
| 촬영 진행 | 사진 3장 촬영 진행 표시 | 참고 |
| 기준점 확인 | 사진의 귀·C7을 지정하고 확인 | 참고 |
| 결과 | 각도 3개와 대표값 표시·저장 | 시안 요청 |
| 기록 | 날짜별 운동 기록과 측정 결과 확인 | 참고 |
| 설정 | 목표·기록 관리 등 설정 | 참고 |

기준점 확인 1/3, 2/3, 3/3은 같은 화면의 진행 상태입니다. 각각 별도의 디자인을 만들 필요는 없습니다.

## 7. AI 활용과 전달 방법

AI로 시안을 만들거나 색상·글꼴·아이콘을 찾는 데 도움을 받아도 괜찮습니다. 최종 제출에는 읽을 수 있는 한국어 문구와 일관된 스타일을 적용해 주세요.

자료는 아래처럼 전달해 주세요.

- `01_style-board.png`
- `02_today.png`
- `03_routine.png`
- `04_result.png`
- `design-notes.md` 또는 같은 내용을 적은 문서: 색상 코드, 글꼴·아이콘 이름, 자료 출처, 사용 조건, 선택 이유
- 편집 가능한 원본 또는 공유 링크가 있다면 함께 전달

PNG는 원래 프레임 크기 또는 2배 크기로 내보내도 됩니다. 예를 들어 `360 × 800` 프레임의 2배 출력은 `720 × 1600`입니다. 어느 크기로 내보냈는지 적어 주세요.

AI를 사용했다면 도구 이름과 시안 생성에 사용한 주요 프롬프트도 함께 적어 주세요. 이미지 속 글꼴·아이콘을 실제 앱에서 쓸 수 있도록, 최종 선정한 자료의 정확한 이름과 출처를 따로 남겨 주세요.

제출 일정은 팀에서 별도로 합의합니다. 자료를 받은 뒤 개발 담당자가 스타일을 선택하고 UX·Figma·실제 앱 반영을 진행합니다.

## 9. 현재 구현된 앱 디자인 참고

아래 이미지는 2026-10-04에 현재 화면 코드를 읽고 만든 **코드 기반 화면 예시**입니다. 실제 갤탭 캡처나 새 디자인 제안이 아닙니다. 표시된 목표·측정값은 예시이며, 갤탭의 실제 저장 상태를 읽은 값이 아닙니다.
